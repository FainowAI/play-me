# Play.Me

Assistente local que transforma playlists do Spotify em sets de DJ: ordem, harmonia (Camelot), BPM, energia e um guia de transições para o Mix do Spotify. Uso pessoal. O código-fonte vive num repositório privado.

## Fontes de dados

- BPM e tom: [GetSongBPM](https://getsongbpm.com) (API)
- BPM de conferência: [Deezer API](https://developers.deezer.com)
- Catálogo e playlists: [Spotify Web API](https://developer.spotify.com)

Nenhum áudio é baixado de nenhum serviço.
